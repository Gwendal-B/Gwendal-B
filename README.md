## 🚀 Projet phare

### 🛒 Kerno — Marketplace B2B locale

`React` · `Vite` · `Node.js` · `Express` · `PostgreSQL` · `Prisma` · `JWT`

Kerno est une marketplace B2B permettant de faciliter la mise en relation entre des **fournisseurs locaux** et des **magasins**.

Le projet a été développé en équipe dans le cadre de ma formation à Holberton School.

#### Fonctionnalités principales

* Création de comptes fournisseur et magasin
* Authentification sécurisée avec JWT
* Gestion des rôles et des autorisations
* Création et modification des profils professionnels
* Gestion d’un catalogue de produits
* Recherche et consultation des fournisseurs
* Envoi et suivi de demandes de mise en relation
* Interface responsive adaptée aux différents utilisateurs
* API REST connectée à une base de données PostgreSQL

#### Contributions techniques

* Développement de composants et pages avec React
* Mise en place de routes publiques et protégées
* Création et intégration d’API avec Express
* Modélisation de la base de données avec Prisma
* Gestion des produits, profils et demandes de contact
* Correction de bugs frontend et backend
* Refactorisation de composants et amélioration de l’expérience utilisateur
* Travail collaboratif avec Git et GitHub

👉 [Voir mon profil GitHub](https://github.com/Gwendal-B)
